# COMP 9060 — Graph Algorithms

An interactive, browser-based slide presentation for **COMP 9060: Applied Algorithm Analysis**, covering graph representations, graph search, and related algorithms.

## 🌐 View the website

**[Open the Graph Algorithms slides](https://aneet11kaur-lgtm.github.io/comp9060-graph-algorithms/)**

No installation or GitHub account is needed to view the presentation.

## 📚 Topics covered

- **Graph fundamentals:** directed and undirected graphs, sparse and dense graphs, and graph size
- **Graph representations:** adjacency matrices, adjacency lists, memory requirements, and trade-offs
- **Graph search:** reachability and generic graph search
- **Breadth-first search (BFS):** queues, exploration layers, pseudocode, examples, and time complexity
- **Shortest paths:** unweighted shortest-path distances and path reconstruction with BFS
- **Connected components:** identifying components using BFS
- **Depth-first search (DFS):** recursive and iterative approaches, stacks, and complexity
- **Topological sorting:** directed acyclic graphs (DAGs), DFS finishing order, and cycle constraints
